# Linux Dotfiles

My personal Arch Linux configuration.

## Environment

- OS: Arch Linux
- WM: Hyprland
- Shell: Zsh
- Terminal: Kitty
- Bar: shell.qml
- Editor: Neovim | VSCodium
- Launcher: Wofi
- Notifications: notifications.qml
- Browser: Brave

## Structure

hypr/       Hyprland configuration
  quickshell/ Quickshell configuration
  modules/ Hyprland modules
  Notifications.qml Notification daemon

## Installation

Clone the repository:

git clone https://github.com/DaviLe-git/dotfiles.git

Then create the appropriate symlinks.
