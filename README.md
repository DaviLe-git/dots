# Linux Dotfiles

My personal Arch Linux configuration.

## Environment

- OS: Arch Linux
- WM: Hyprland
- Shell: Zsh
- Terminal: Kitty
- Bar: Quickshell
- Editor: Neovim | VSCodium
- Launcher: Wofi
- Notifications: ...
- Browser: Brave

## Structure

hypr/       Hyprland configuration
quickshell/ Quickshell configuration
nvim/       Neovim configuration
kitty/      Kitty configuration
bar-quickshell/     Personalized QuickShell bar
zsh/        Zsh configuration

## Installation

Clone the repository:

git clone https://github.com/DaviLe-git/dotfiles.git

Then create the appropriate symlinks.
